# LibraAI

AI-powered research assistance for university libraries.

## 📌 Project Overview

LibraAI is a web application designed to help university students find concise, citation-backed answers from academic resources such as research papers, theses, and course materials.

Instead of manually searching through multiple documents, students can ask questions and receive relevant answers supported by citations from the available sources.

## 🎯 Problem Statement

A university library holds research papers, theses, and course materials, yet students cannot get concise, citation-backed explanations and instead scroll through dozens of unrelated documents for one answer.

LibraAI aims to make academic information easier to discover, understand, and reference.
